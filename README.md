# مصدر موقع شركة الميثاق

هذا الفرع (`source`) يحتوي ملفات بناء الموقع. الموقع المنشور نفسه في الفرع `main` ويظهر على https://almeithaq.github.io

## أين أعدّل البيانات
كل بيانات الموقع في ملف واحد: `src/site-data.ts`
- الأصناف (النوع، المقاس، بلد الصناعة، اللمعات): `products`
- أرضيات صالة العرض التفاعلية: `floorLooks`
- العروض والتخفيضات: `offers`
- الفروع والعناوين وأرقام الموظفين وساعات العمل: `branches` و `workHours`
  - لتفعيل زر واتساب لرقم معين أضف `whatsapp: true` بجانبه.
  - لإضافة موقع الفرع على الخريطة أضف `mapUrl`.
- صفحات التواصل: `socials`

بيانات العميل الكاملة والمعلومات الناقصة في `CLIENT_BRIEF.md`.

## البناء
```
npm install
npm run typecheck
npm run build
```
الناتج في مجلد `dist`، وتُنسخ محتوياته إلى الفرع `main` للنشر.
