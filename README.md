# مصدر موقع شركة الميثاق

هذا الفرع (`source`) يحتوي ملفات بناء الموقع. الموقع المنشور نفسه في الفرع `main` ويظهر على https://almeithaq.github.io

## أين أعدّل البيانات
كل بيانات الموقع في ملف واحد: `src/site-data.ts`
- الأصناف حسب بلد الصناعة: `origins`
- العروض والتخفيضات: `offers`
- الفروع والعناوين والأرقام وساعات العمل: `branches`
- صفحات التواصل: `socials`

## البناء
```
npm install
npm run typecheck
npm run build
```
الناتج في مجلد `dist`، وتُنسخ محتوياته إلى الفرع `main` للنشر.
